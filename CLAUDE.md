# CLAUDE.md — n8n Self-Hosted Deployment

## Project Overview

Self-hosted n8n workflow automation platform deployed via Docker Compose on a Linux VM.

- **Stack**: n8n (Docker) + PostgreSQL 16 (Docker) + nginx (host) + upstream SSL termination

## Architecture

```
Internet → Load Balancer / Cloudflare (SSL termination) → nginx :80 → 127.0.0.1:5678 → n8n container → postgres container
```

- SSL is terminated upstream — nginx listens on port 80 only
- n8n binds to `127.0.0.1:5678` (loopback only)
- PostgreSQL runs on an internal Docker network, not exposed

## Key Files

| File | Purpose |
|------|---------|
| `.env` | Generated by `deploy.sh` — live config with secrets (chmod 600, never commit) |
| `docker-compose.yml` | Generated by `deploy.sh` — n8n + postgres services |
| `deploy.sh` | First-time deployment script |
| `update.sh` | Pull latest n8n image + restart (runs backup first) |
| `backup.sh` | Dump postgres + archive n8n-data to `backups/` |
| `uninstall.sh` | Stop containers + remove nginx config |

## Important Notes

- **No certbot / Let's Encrypt on the server** — SSL is handled upstream
- Nginx config lives at `/etc/nginx/sites-available/n8n` (symlinked to sites-enabled)
- Execution data is pruned after 168 hours (7 days) by default
- Backups in `backups/` are auto-pruned after 30 days
- Secrets are in `.env` (git-ignored) — never commit this file

## Common Commands

```bash
docker compose logs -f n8n       # view n8n logs
docker compose restart n8n       # restart n8n
docker compose down && docker compose up -d  # full restart
./backup.sh                      # manual backup
./update.sh                      # update to latest version
```
