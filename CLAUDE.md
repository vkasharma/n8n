# CLAUDE.md — n8n Self-Hosted Deployment

## Project Overview

Self-hosted n8n workflow automation platform deployed via Docker Compose on a Linux VM.

- **Stack**: n8n (Docker, `stable` tag) + PostgreSQL 16 (Docker) + nginx (host)
- **Host**: Oracle Cloud VM (Ubuntu 24.04, 1 GB RAM + 2 GB swap), no domain. Served over plain HTTP on the public IP (`ACCESS_MODE=ip`)

## Architecture

```
IP mode (current):  Internet → nginx :80 → 127.0.0.1:5678 → n8n container → postgres container
Domain mode:        Internet → LB / Cloudflare (SSL) → nginx :80 → 127.0.0.1:5678 → n8n → postgres
```

- nginx listens on port 80 only. In IP mode it's the `default_server` catch-all (the stock `default` site is disabled)
- n8n binds to `127.0.0.1:5678` (loopback only)
- PostgreSQL runs on an internal Docker network, not exposed
- IP mode requires `N8N_SECURE_COOKIE=false` (no HTTPS)

## Key Files

| File | Purpose |
|------|---------|
| `.env` | Generated by `deploy.sh` — live config with secrets (chmod 600, never commit) |
| `docker-compose.yml` | n8n + postgres services; all values come from `.env` |
| `deploy.sh` | First-time deployment script (installs Docker/nginx, swap, opens port 80) |
| `update.sh` | Backup, pull image for `N8N_VERSION` + restart |
| `backup.sh` | Dump postgres + archive n8n-data/local-files to `backups/` |
| `uninstall.sh` | Stop containers + remove nginx config |

## Important Notes

- **No certbot / Let's Encrypt on the server** — no domain. HTTPS would need e.g. an sslip.io hostname plus certbot
- Oracle images ship iptables rules that REJECT everything except SSH. deploy.sh inserts a port 80 ACCEPT rule live and in `/etc/iptables/rules.v4`. The VCN security list must also allow TCP 80
- Scripts re-exec themselves with sudo (n8n-data is uid 1000 with 600 files; docker needs root)
- n8n 2.x: file nodes are restricted to `/files` (`N8N_RESTRICT_FILE_ACCESS_TO`, mapped to `./local-files`). Execute Command node is disabled by default. Python Code node needs an external task runner (not set up)
- Nginx config lives at `/etc/nginx/sites-available/n8n` (symlinked to sites-enabled)
- Execution data is pruned after 168 hours (7 days) by default
- Backups in `backups/` are auto-pruned after 30 days
- Secrets are in `.env` (git-ignored) — never commit this file

## Common Commands

```bash
docker compose logs -f n8n       # view n8n logs
docker compose restart n8n       # restart n8n
docker compose up -d             # apply .env changes
./backup.sh                      # manual backup
./update.sh                      # update to latest stable version
```
